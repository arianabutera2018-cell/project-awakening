# Prévias no Blender

Estas imagens foram geradas pelo Blender a partir do arquivo `world/Temple.model.json`.
Elas servem **só para conferir posições, tamanhos e cores** do cenário.

**Não são capturas do jogo no Roblox.** A iluminação, o brilho e os materiais do Roblox ficam diferentes.
Os personagens e a interface não aparecem aqui.
